# 🎵 Jump, Jump, Wiggle! - Kids Music Video

A fun animated music video for kids built with HTML5 Canvas!

## 🎬 How to Use

### Watch Online (GitHub Pages):
Once GitHub Pages is enabled, visit: `https://oubella22.github.io/Kids-music/`

### Add Your Music:
1. Upload your audio file to this repo and name it `music.mp3`
2. The animation will automatically play your music when you hit Play!

## 🎶 Features
- 2:30 animated music video
- Colorful cartoon characters (kid, monkey, bunny, bird, lion)
- 9 different scenes with unique backgrounds
- Synced bouncing lyrics
- Confetti and particle effects
- Works in any browser — no software needed!

## 📁 Files
- `index.html` — The full animation (open in browser)
- `music.mp3` — Your audio file (add this yourself)

## 🚀 How to Add Music
1. Click "Add file" → "Upload files" on this GitHub page
2. Drag your MP3 file (rename it to `music.mp3`)
3. Commit the changes
4. Done! The video will play with your music!
